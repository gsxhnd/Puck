## 2. 主要技术风险

| 风险 | 影响 | 缓解策略 |
| --- | --- | --- |
| PTY 跨平台差异 | 本地终端不可用或行为不一致 | 优先选择成熟 Rust PTY 库，按平台封装 |
| Windows WSL 检测差异 | WSL 发行版识别失败 | 允许用户手动配置 shell |
| SSH host key 策略复杂 | 安全风险或连接体验差 | 首版明确提示并持久化用户确认 |
| FTPS TLS 兼容性 | 部分服务器无法连接 | 首版优先显式 FTPS，暴露必要错误细节 |
| 大文件传输 | UI 卡顿或中断恢复困难 | 后端流式传输，前端只接收进度事件 |
| 凭据存储差异 | 不同系统钥匙串行为不一致 | 抽象 Credential Service，并保留“不保存凭据”降级策略 |
| 终端快捷键冲突 | 常用终端程序无法正常操作 | 对终端区域和全局快捷键做作用域区分 |
| 主题可读性 | 颜色组合导致不可读 | 终端主题独立配置，内置主题人工验证 |

## 3. 验收标准

### 3.1 本地终端

- 应用启动后可以打开默认本地 shell。
- macOS/Linux 可识别 zsh 和 bash。
- Windows 可识别 PowerShell、cmd，并检测 WSL。
- 输入、输出、Ctrl+C、Ctrl+D、方向键正常。
- 调整窗口大小后终端布局正常。

### 3.2 SSH

- 可以创建并保存 SSH 连接。
- 可以使用密码认证连接测试服务器。
- 可以使用私钥认证连接测试服务器。
- 首次 host key 可以确认并保存。
- 断开连接后前端状态正确显示。
- 可以关闭 SSH 标签并释放后端资源。

### 3.3 SFTP

- 可以从 SSH 连接打开 SFTP 文件管理器。
- 可以列出远程目录。
- 可以上传和下载文件。
- 可以删除、重命名、新建目录。
- 传输进度、成功、失败状态正确。

### 3.4 FTP / FTPS

- 可以创建 FTP 连接并浏览目录。
- 可以创建显式 FTPS 连接并浏览目录。
- 可以上传和下载文件。
- 认证失败、连接超时、权限不足有明确提示。

### 3.5 UI / 主题 / 多语言

- 中英文切换后主要 UI 文案更新。
- Light、Dark、System 正常切换。
- 终端主题切换后当前终端立即更新。
- 连接列表、终端标签、文件管理器在 800x600 窗口下不重叠。
- 图标按钮有 tooltip 或可访问标签。

## 4. 测试策略

### 4.1 单元测试

Rust：

- 连接配置序列化与校验。
- shell 检测逻辑。
- 错误类型映射。
- 凭据 key 生成。

TypeScript：

- 连接表单校验。
- i18n key 覆盖。
- theme token 映射。
- session reducer/store 状态变化。

### 4.2 集成测试

- 前端通过 mock IPC 测试终端事件流。
- Rust 使用可控测试服务器验证 SSH/SFTP。
- FTP/FTPS 使用本地测试容器或测试服务验证基础操作。
- 传输队列测试成功、失败、取消、重试。

### 4.3 手动测试

- macOS：zsh、本地终端、SSH、SFTP。
- Windows：PowerShell、cmd、WSL、SSH、FTP/FTPS。
- Linux：bash/zsh、SSH、SFTP。
- 主题切换、语言切换、窗口缩放。

## 5. 发布前检查清单

- 所有 Tauri IPC 命令已注册。
- Tauri capabilities 只包含必要权限。
- 配置文件不包含明文密码。
- 关闭标签会释放后端资源。
- 大文件传输不会阻塞 UI。

- 默认主题下终端可读。
