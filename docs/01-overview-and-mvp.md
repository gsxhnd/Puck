# Puck Terminal 文档：产品总览与当前能力

## 1. 产品定位

Puck Terminal 是一个基于 Tauri 的桌面终端与文件传输工作台，面向需要同时管理本地 shell、远程 SSH 会话和 SFTP 文件操作的开发者与运维用户。

当前阶段的重点已经从基础搭建转向可用性与 UI 细节打磨：核心链路已经打通，后续工作应优先围绕交互一致性、错误可理解性、视觉层级和跨平台稳定性展开。

## 2. 当前核心能力

### 本地终端

- 通过 Rust 后端创建本地 PTY。
- 前端使用 xterm.js 渲染终端输入输出。
- 支持默认 shell 和可选 shell 会话。
- 支持 resize、复制粘贴、链接识别、搜索插件基础接入。
- 支持应用主题与终端主题配置。

### SSH 终端

- 支持创建、编辑、复制、删除 SSH 连接配置。
- 支持密码认证和私钥认证。
- 密码与私钥口令写入系统钥匙串，不进入普通前端持久化配置。
- 首次连接未知 host key 时弹出确认，并持久化信任记录。
- 支持远程交互式 shell、终端输入输出、resize、断线状态展示和手动重连。

### SFTP 文件管理

- SSH / SFTP 连接可以打开远程文件管理器。
- 支持远程目录浏览、路径面包屑、刷新、进入目录和返回上级。
- 支持上传、下载、新建目录、删除、重命名。
- 上传下载通过后端流式传输，并向前端推送进度事件。
- 传输队列支持进度展示、成功/失败状态、失败重试和清除已完成任务。

### App Shell 与基础体验

- 左侧连接侧边栏支持搜索、协议筛选、新建连接和更多操作菜单。
- 主工作区支持本地终端、SSH 终端、文件管理器、设置页多标签共存。
- 顶部提供会话标签、传输队列入口和命令面板入口预留。
- 设置页支持语言、主题、终端字体、字号、终端主题等基础偏好。
- i18n 已按模块组织，当前支持 `zh-CN` 和 `en-US`。

## 3. 当前明确限制

- FTP / FTPS 连接配置已经在模型和 UI 中预留，但文件传输后端尚未实现；当前文件管理器只支持 SFTP。
- SSH Agent、ProxyJump、端口转发、目录同步、远程文件预览暂未实现。
- 传输任务支持失败重试，但取消、暂停、恢复还不是完整能力。
- 全局命令面板入口已预留，完整命令搜索与快捷键体系尚未完成。
- 当前连接配置由前端 Zustand 持久化管理，后续如需更强的数据迁移能力，可再引入结构化配置仓库。

## 4. 主要用户流程

### 打开本地终端

1. 用户进入应用。
2. 应用根据设置决定是否自动打开本地终端。
3. 用户可以通过“新建终端”打开默认 shell 或指定 shell。
4. xterm.js 将用户输入转发给 Rust PTY，并渲染后端输出。

### 打开 SSH 终端

1. 用户创建或选择一个 SSH 连接配置。
2. 如使用密码或私钥口令，敏感信息保存到系统钥匙串。
3. 首次连接新主机时，用户确认 host key。
4. 连接成功后打开远程 shell 标签。
5. 断开后展示状态，用户可以手动重连。

### 使用 SFTP 文件管理器

1. 用户从 SSH 或 SFTP 连接打开文件管理器。
2. 应用建立独立的 SFTP 会话。
3. 用户浏览目录并执行上传、下载、新建目录、删除、重命名。
4. 传输任务进入队列，显示进度、完成或失败状态。

## 5. 术语

| 术语 | 定义 |
| --- | --- |
| Profile | 可复用的连接配置，包括协议、主机、端口、用户名、认证方式、默认目录等 |
| Session | 运行中的终端或文件连接实例，对应一个前端标签和一个后端资源 |
| Credential | 密码、私钥口令等敏感信息，通过系统钥匙串保存 |
| Terminal Pane | 承载 xterm.js 实例的终端区域 |
| File Manager | SFTP 远程文件浏览和操作界面 |
| Transfer Queue | 上传下载任务列表，接收后端进度事件 |
| Known Hosts | 已信任的 SSH 主机密钥记录 |

## 6. 当前整理原则

后续微调 UI 时，文档以当前功能为基准：

- 不再把 SSH / SFTP 描述为未开始的未来目标。
- FTP / FTPS、SSH Agent、命令面板增强等能力放入后续方向。
- UI 修改应优先保持现有架构边界：前端负责交互和状态，Rust 负责系统资源、网络连接与凭据。
- 新增样式或交互要同步检查中英文文案、暗色模式、窗口缩放和标签切换。
